# NumericControls.Demo

Demo application showcasing the NumericControls library.

## Purpose

Demonstrates numeric-specific controls for statistical and scientific data entry, including distribution parameters, ordinate row items, and math editor functions.

## How to Run

```
dotnet run --project src/NumericControls.Demo/NumericControls.Demo.csproj
```

Requires external Numerics.dll from the sibling `numerics` repo.

## What It Demonstrates

- Numeric controls for statistical data (parameters, summary statistics)
- Distribution row items and probability ordinate editors
- Includes sample USGS data file (USGS_01134500.xml) as embedded resource
