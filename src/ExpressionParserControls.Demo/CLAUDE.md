# ExpressionParserControls.Demo

Demo application showcasing the ExpressionParserControls library.

## Purpose

Demonstrates the CalculatorControl -- a WPF control that provides an interactive expression editor with live evaluation using the ExpressionParser library.

## How to Run

```
dotnet run --project src/ExpressionParserControls.Demo/ExpressionParserControls.Demo.csproj
```

## What It Demonstrates

- CalculatorControl with expression input and live result display
- ExpressionChanged event handling for real-time evaluation feedback
