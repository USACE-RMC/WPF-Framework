# GenericControls.Demo

Demo application showcasing the GenericControls library.

## Purpose

Demonstrates input controls (NameTextBox, NumericTextBox, NumericUpDown, NumericSlider), date/time controls (ClockControl, DateAndTimeTextBox), color controls (ColorPicker, ColorPickerPopup), property editor controls, file/folder selectors, CopyPasteDataGrid, and theme switching.

## How to Run

```
dotnet run --project src/GenericControls.Demo/GenericControls.Demo.csproj
```

## What It Demonstrates

- Tabbed layout with 6 tabs: Input Controls, Date/Time/Color, Property Editors, File/Folder, DataGrid, Color Collection
- Theme switching between Light, Blue, and Dark via radio buttons
- Live preview panel showing bound property values
- CopyPasteDataGrid with toolbar, context menu, and row operations
